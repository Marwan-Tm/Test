# My PWA App - Progressive Web App (PWA)

This project is a fully configured Progressive Web App (PWA). That means it can run in the browser AND be installed on mobile phones and desktops natively.

## How to use:
1. Extract the contents of this ZIP file.
2. Upload the files to any free static web host (like GitHub Pages, Vercel, Netlify, or Surge).
3. Open the hosted URL on your phone or computer.
4. Your browser will prompt you to "Install App" or "Add to Home Screen".
5. Once installed, it behaves like a native app (with its own window, icon, and offline support)!
